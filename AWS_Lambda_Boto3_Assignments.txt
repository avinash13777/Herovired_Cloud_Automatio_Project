================================================== ASSIGNMENT 1:
Automated EC2 Instance Management
==================================================

Objective: Automate the starting and stopping of EC2 instances based on
tags.

Resources Created: - AWS_Lambda_Stop (Action=Auto-Stop) -
AWS_Lambda_Start (Action=Auto-Start)

IAM Role: - LambdaEC2ManagerRole

Policies: - AmazonEC2FullAccess - AWSLambdaBasicExecutionRole

Lambda Function: - EC2AutoManager

Steps Performed: 
1. Created two EC2 instances. 
2. Added tags Auto-Stop
and Auto-Start. 
3. Created IAM Role. 
4. Attached required policies. 
5.Created Lambda function. 
6. Used Boto3 to describe, stop, and start
instances. 
7. Manually invoked Lambda. 
8. Verified EC2 state changes.

Outcome: Successfully automated EC2 start and stop operations.

================================================== ASSIGNMENT 5:
Auto-Tagging EC2 Instances
==================================================

Objective: Automatically tag newly launched EC2 instances.

IAM Role: - LambdaEC2AutoTagRole

Policies: - AmazonEC2FullAccess - AWSLambdaBasicExecutionRole

Lambda Function: - EC2AutoTagger

EventBridge Rule: - EC2LaunchTagRule - Event Bus: default

Tags Added: - LaunchDate - Environment=Dev

Steps Performed: 1. Created IAM Role. 2. Created Lambda Function. 3.
Added Boto3 code. 4. Created EventBridge Rule. 5. Connected Lambda as
target. 6. Launched EC2 instance. 7. Verified automatic tagging.

Outcome: Successfully implemented event-driven EC2 auto-tagging.
